1结论摘要

≈90%
核心功能与工作流可以复刻，且成本大幅下降、数据完全自有。

把「记录 → 记忆 → 检索 → 四大 AI 能力 → 8 专家协作创作 → 品控 → 排版导出」这条主链路拆开看，绝大多数环节已有成熟开源件或可用 Agent + Prompt 编码实现。真正无法合法复刻的只有一处：得到自有的十年版权内容库（课程/电子书/听书），它是「张素材」调研能力的弹药来源。

可高保真复刻

知识库、全文/语义检索、记忆库、发芽/点评/拷问/润色、录音转写逐字稿、作品创作、8 位写作专家、金线品控、排版导出。

可近似复刻

「越用越主动」的主动提醒、「小步眼中的你」画像、声纹识别、多端同步体验——靠脚本 + 规则 + 推送底座可逼近，但工程量与丝滑度不如原生。

无法合法复刻

得到十年课程/电子书/听书版权库、官方 AI 录音卡硬件与离线续航、金线 Skill v3.3 内部训练模型（只能用公开的「金线 9 条」规则近似）。

一句话判断：把 Obsidian 当「数据底座 + 记忆库」，把 AI 智能体当「四大能力 + 8 人专家团」，把已有的企微推送底座当「主动性」，就能拼出专家版 90% 的体验；省下的近 3000 元/年，代价是需要一次性搭建（P0 约 1–2 天）并自行维护。

2.2 三层能力模型（会员/专家版共有底座）

  • 4 个主动技能：点评（发现你没注意到的闪光点）、发芽（从记录延伸出新认知）、拷问（把想法想透、经得起挑战）、润色（润色成可发布的作品）。
  • 3 个底层能力：主动性（你产生行为它就主动出现）、记忆（说过/学过/记录过的全记得）、得到十年内容资产（课程/电子书/听书与想法碰撞）。
  • 产品化形态：小步 AI（猫头鹰助手）、待办 / 日记 / 发芽报告、记忆库（记忆资产·时间线）、成果（作品）、多端（iOS/安卓/鸿蒙/Mac/Win/浏览器插件/小程序/网页 + 录音卡硬件）。

典型协作流程（官方示例）：一句话想法 + 照片 + 3 分钟语音 → 赵选题给 3 个角度 → 张素材找引用/数据/案例 → 李文章起稿 1200 字 → 吴查查核查纠错 → 周审稿审结构逻辑 → 刘风格按画像调语气 → 陈排版出 3 个版本 → 王整理存回知识库。8 个角色既可全流程串行，也可单独调用。

2.4 「得到金线」品控（专家版护城河之一）

即发布 9 年的《得到品控手册》第 10 年的 AI 化形态（Skill v3.3）。核心设定：只做品控、不写稿；判断标准是「内容能否帮用户完成一次认知改变」；反馈由「原文 / 问题 / 建议」三部分构成，分 4 类——金线提升建议、文本优化建议、核查提示、风险提示；并采用「粗评（任务成立性）→ 细评」两段式，不成立则先提示修改方向。

这恰恰是最容易被复刻的部分：金线 9 条准则（知识服务、对象感、以用户挑战开篇、克服炫技、制造认知落差、管理注意力、消除理解障碍、便于带走、尊重看不见的人）是公开、显性、可编码的规则——把 9 条 + 4 类反馈 + 粗评/细评流程写成一个 Skill/Rubric Prompt 即可复用。

3Obsidian + AI 的现成弹药（不用从零造轮子）

调研发现：针对「得到大脑 → Obsidian」这条链路，社区已有 4 个成熟开源项目；通用 AI 插件生态也已能覆盖四大能力与专家团编排。

3.1 专为「得到大脑 / Get笔记 → Obsidian」而生的项目

GongziTANG/getnote-to-obsidianApache-2.0 · 2026 · AI 辅助开发

最值得关注。单向只读同步，把录音/文字记录搬进 Obsidian，还补齐官方导不出的带说话人+时间轴的逐字稿、发芽报告（含未保存的）、追加笔记、音频原件；带自动归档路由、标签库、每日灵感、日/周/月时间日记、日志与回滚。5 个幂等脚本 + 定时任务即可全自动。凭据走开放 API + 逆向 web 接口（发芽需额外 web token）。附完整 SKILL.md，可作为 Agent 技能直接调用。

AndyZhengyan/obsidian-dedao-brain-sync标注「官方推荐」

双向同步（Obsidian ↔ 得到大脑），仅支持 OpenAPI；默认关闭自动上传、不传播删除、保留冲突两端供手动选择。适合想「两边写、自动同步」的场景。

AndyZhengyan/oh-my-getnoteMIT · Next.js 16 + LanceDB

定位 Memex 记忆增强器：把导出内容编译成 LLM-friendly 语料库，做向量多跳关联、可视化思维轨迹 Trails、语义补完。不是 Obsidian 插件，但其「知识为 AI 消费而优化」理念可直接借鉴来增强 vault。

Dedao KB Sync（Obsidian 官方插件商店）已上架商店 · 一键安装

把得到大脑的课程笔记、听书心得自动同步成本地 Markdown，30+ 知识库约 15 分钟搬完、之后自动更新。零代码门槛，适合快速把存量笔记拉进本地。

5推荐架构：四层拼装

① 采集层
getnote sync / 录音转写 / 剪藏→ ② 底座层
Obsidian vault = 知识库+记忆库→ ③ 智能层
Copilot V4 Agent + 四大能力 + 8专家→ ④ 输出与主动层
金线品控 / 排版导出 / 企微推送

① 采集层

getnote-to-obsidian 拉存量 + 增量；录音走现有 ASR；网页/公众号用 Web Clipper。落到本地 md，单向入库。

② 底座层

vault 即唯一真源。Dataview/Templater/Linter 规范元数据；Smart Connections + miyo 建语义索引；Git/Remotely Save 做版本与同步。

③ 智能层

一份 AGENTS.md 定义 8 个角色及技能，四大能力做成自定义命令；金线 9 条封装成独立 Skill；模型走智谱免费额度或已有订阅。

④ 输出与主动层

走完创作流水线后由「周审稿+金线」过品控、「陈排版」出多版本；主动提醒/待办/发芽报告复用 server_notify 推到企微。

赵选题→ 张素材→ 李文章→ 吴查查→ 周审稿 + 金线→ 刘风格→ 陈排版→ 王整理入库

7风险与边界（诚实说明）

合规风险：getnote-to-obsidian 的逐字稿/发芽依赖对官方 web 接口的逆向，官方一更新就可能失效；项目方声明「仅用于导出你自己的数据」。用于个人数据迁移问题不大，但不要做二次分发或商业化。
  • 内容缺口：「张素材」失去得到十年版权弹药，调研深度会打折——可用联网检索 + 你自己的知识库部分弥补，但无法等同于官方。
  • 主动性体验：脚本定时推送能解决「主动找你」，但「基于行为判断时机」的自然度需要长期调教规则。
  • 维护成本：逆向接口、插件升级、模型额度都需要偶尔照看；这是「省钱」换来的唯一代价。
  • 模型质量：免费额度模型跑四大能力与专家团，质量低于官方可能的专用模型；关键产出可切付费/更强模型。
