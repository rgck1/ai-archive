## 一、结论先行

`轮动验证_退市压力测试.py` 在 2026-11-22 的逐日盯市（MTM）改造中引入了一个静默失效：暴雷冲击只写入了 `rr`，而盯市净值读取的是 `rc`（ret_clean）日收益矩阵，`rr` 修改后再无人读取。结果是压力测试在 0% / 1% / 3% / 5% 四档暴雷率下输出完全相同，名义上测了幸存者偏差，实际没有施加任何冲击。

已修复两处根因，压力测试恢复正确语义：温和档净值倍数随暴雷率单调递减。极端下界档（每期最差票 -80%）净值归零，数学正确，作为"每期必有票暴雷"的不可持续上界压力保留。

## 三、根因

### 根因 1：冲击写错变量（静默失效，阻断级）

修复前代码片段（第 66-79 行）：

```python
rr = np.clip(spx[good] / bp[good] - 1.0, -0.6, 1.0) - cost
if extreme and len(rr) > 1:
    rr[np.argsort(rr)[0]] = -0.8 - cost
elif annual_rate > 0 and rng.random() < p_event and len(rr) > 1:
    rr[rng.integers(len(rr))] = -0.6 - cost
# [MTM 修复] 逐日盯市替代平摊收益
held = sel[good]; seg0, seg1 = t - i0, si - i0
rc = np.asarray(p.ret_clean, dtype=float)
for pos in range(seg0 + 2, min(seg1 + 1, len(rets))):
    rd = rc[pos + i0, held]          # 净值只读 rc，rr 的冲击完全无效
    rd = np.where(np.isfinite(rd), rd, 0.0)
    rets[pos] = float(np.mean(np.clip(rd, -0.11, 0.11)))
```

MTM 改造前，净值由 `rr` 的平摊收益构造，改 `rr` 有效；改造后净值改由 `rc` 逐日盯市构造，旧代码只替换了收益构造部分，忘了把冲击注入同步迁移，导致 `rr` 变成无人读取的死变量。这正是 E 在独立审查中提示的"压力测试语义可能失效"风险点。

### 根因 2：暴雷触发概率口径错误（重要级）

修复前：`p_event = annual_rate / 12.0`，并把它当作"每期组合层面触发一次暴雷"的概率。5% 年化率下 p_event 仅 0.42%，全样本约 44 期，期望触发不到 0.2 次，多种子取中位数后几乎必然抹平。脚本注释写的是"年化暴雷率"，应解释为"每只持仓股每年暴雷概率"，两者口径不一致。

## 四、修复内容

文件：`轮动验证_退市压力测试.py`，备份 `轮动验证_退市压力测试.py.bak-preShockFix-20261122`。

### 修复 1：冲击注入 rc 矩阵

- 中招票确定后，在其持仓窗口内按连续跌停路径覆盖 `rc`：每日 -10%，连续 n 日使累计损失达到目标，n = ceil(log(1+loss) / log(0.9))。温和档 loss=-0.60 → n=9 日累计 -61.3%；极端档 loss=-0.80 → n=16 日累计 -81.5%。均为 A 股主板跌停 10% 约束下的现实路径。
- 冲击起点在持有期内随机选取，需留出 n 日跌停窗口；窗口之后该票按退市/长期停牌记 0。
- 收益仍按当日持仓等权平均，成本仍在建仓日扣一次，与生产引擎口径一致。

### 修复 2：触发概率按持仓数放大

```python
p_per_stock = annual_rate / 12.0
p_event = 1.0 - (1.0 - p_per_stock) ** topn if annual_rate > 0 else 0.0
```

每只票每月暴雷概率 = 年化率/12；每期至少一只中招概率按持仓数 topn 放大。5% 档、topn=20 时约每期 8%，44 期期望触发约 3.5 次，能观察到明确差异。

### 清理

- 删除 `xbx_engine.py:413` 的死变量 `rr`（MTM 改造遗留，同样无人读取），导入与 cross_section 调用验证通过。
- 删除本次修复中引入的未使用变量 `hit_code`。

## 六、口径边界与局限

- 连续跌停 -10%/日为主板简化模型。ST 股跌停 -5%、北交所 -30%、创业板/科创板 -20%，本脚本统一按 -10%，会低估这些板块的冲击速度，属保守方向。
- 暴雷后按退市/长期停牌记 0 收益，未建模退市整理期流动性折价与残余价值回收，方向偏保守。
- p_event 按持仓数放大，隐含"持仓股暴雷相互独立"假设。真实暴雷有行业/市场相关性，集中暴露时会低估尾部风险。
- 压力测试基于当前存续股票面板，仍含幸存者偏差；本测试是给幸存者面板叠加退市冲击做近似补偿，不等于完整历史退市股回测。
- 极端下界档的每期必触发假设不现实，仅作不可持续性证明，不用于绩效评估。
