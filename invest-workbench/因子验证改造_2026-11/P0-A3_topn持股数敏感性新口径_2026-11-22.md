# topn 持股数敏感性：新口径全量复核

日期：2026-11-23 ｜ 负责人：A（team-lead）｜ 状态：结果已落盘，待 E 独立复核措辞

## 一、结论先行

1. **30 组（2 口径 × 5 档 topn × 3 信号）中，常规门槛 3 组 PASS、严格门槛 0 组 PASS。** 3 组常规 PASS 均无参数邻域支撑，是孤立尖点，判定为多重比较下的运气结果，不作为可用因子证据。
2. **锁定 topn=20 的主口径结论不变。** 主口径冠军因子（topn=20）三信号仍全部 FAIL，与第三口径、pit 口径一致。topn 敏感性测试的作用是检验结论是否依赖持股数，答案是：没有任何一档能稳定通过严格门槛，主结论稳健。
3. **常规 PASS 的三组集中在两个信号的边缘档位**：冠军B main topn=15、冠军C main topn=30、冠军C pit topn=30。共同特征是全期分位达标但样本外分位勉强，或只在单一持股数点达标，换相邻档位即失效。
4. **严格门槛 0 组 PASS 是更可信的结论。** 30 次比较下，常规门槛 pct≥0.90 会被随机波动命中若干次；严格门槛（0.983，Bonferroni 校正）无一命中，说明没有任何组合强到能扛住多重比较校正。

## 四、为何 3 组常规 PASS 不采信

### 4.1 无参数邻域支撑，全是孤立尖点

有效因子应在相邻持股数档位表现连续。实测 3 组 PASS 都不满足：

- **冠军B main**：pctF 在 topn=5 达 0.980、10/15 为 0.930，看似有邻域；但 pctO 全程只有 0.84-0.91，从未到 0.90 以上稳定区间。唯一 PASS 的 topn=15 是 pctF 与 pctO 偶然同时越线（0.930/0.910），topn=10 的 0.930/0.870 和 topn=20 的 0.870/0.855 都失败。两个分位高值不重叠。
- **冠军C main**：pctF 随 topn 单调抬升，0.255→0.485→0.615→0.775→0.930，只在最末档 30 越线；pctO 虽在 30 达 1.000，但 topn=25 附近的连续性未验证，且这是被搜索出来的一端极值。
- **冠军C pit**：与 main 同信号同档位 PASS，但 pit 口径本身含静态前视，不作真值，不能作为独立佐证。

### 4.2 多重比较下常规门槛会被随机命中（E 第十三节量化）

30 组比较，即使全部是无效应信号，pct≥0.90 在多次比较中也会自然出现若干次。E 做了两项量化：

**概率估算**：零假设下 pctF 与 pctO 近似独立（实测相关系数仅 0.061），单组同时≥0.90 概率约 0.01，30 组中至少出现 1 组的概率为 1−0.99³⁰≈26%。实测经验边缘 P(pctF≥0.9)=0.200、P(pctO≥0.9)=0.500，联合频率 0.100 恰等于独立预期。出现 3 组 PASS 完全在多重比较的预期范围内。

**Bonferroni 门槛的真实校正范围**：严格线 0.983 在 NPL=200 下是 ≥197/200，只校正了 3 个信号（m=3，α≈0.015），**没有覆盖 5 档 topn 与 2 个口径**。若真正覆盖 30 组比较，门槛应设 0.9983，即 200/200 全部跑输。3 组 PASS 的 pctF 最高 0.930（186/200），距此还差 14 次，全部不达标。这不是缺陷，而是提示：多次参数搜索下 NPL=200 的分辨率不足以在校正后仍保持检验效力，需把 NPL 提到 1000 以上，或预先锁定参数减少比较次数。

实测严格门槛（0.983）0 组通过，已部分校正信号维度；常规门槛的 3 组 PASS 落在"30 次里挑最好几次"的预期范围内，两者都不构成有效证据。

### 4.3 topn 是事后搜索维度，不能反向挑选

主口径冠军因子锁定 topn=20（与历史口径一致）。topn 敏感性测试的目的是看结论是否依赖这个选择，而非提供"换个持股数就能用"的备选。若允许事后从 5 档里挑最好的一档上线，本身就是数据窥探，PCT 分位会系统性高估。因此即便某档常规 PASS，也不构成改变主口径的理由。

## 五、口径边界与解读纪律

1. **"严格 0 组 PASS"的含义**：没有任何 topn/信号/口径组合能通过多重比较校正后的门槛。这**不等于被证否**，也不等于负收益——30 组全期倍数多在 1.2-2.4 之间，样本外多为正。含义是证据不足以支持对外宣称有效。
2. **常规 PASS 如实列出但不推广**：报告列出 3 组常规 PASS 以满足透明度，同时明确其孤立尖点性质和不予采信的理由，避免被当作"找到了可用参数"。
3. **跨信号、跨 topn 分位不可横向对比**：安慰剂域逐信号独立，不同 topn 的安慰剂分布也不同，分位数只与同信号同档位的真实值比较。
4. **pit 口径仅作对照**：含静态前视，其 PASS 不作为有效证据。

## 六、业务结论

1. 主口径结论稳健：冠军因子在锁定 topn=20 下三信号全 FAIL，topn 5/10/15/30 四档同样没有任何一组能通过严格门槛，结论不依赖持股数选择。
2. 3 组常规 PASS 判定为多重比较运气，不转化为可用因子，不进入前端展示，不用于实盘。
3. 方法论资产：topn 敏感性作为"维度稳健性检查"的流程可复用——搜索维度必须配套 Bonferroni 校正、参数邻域连续性检查、锁定主参数禁止事后挑选。
