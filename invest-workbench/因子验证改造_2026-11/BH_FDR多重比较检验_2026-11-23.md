# BH-FDR 多重比较检验报告（q = 0.10）

日期：2026-11-23。对照方法：Bonferroni。检验统计量：p = 1 - pct。

## 1. 一句话结论

全量族 39 个检验与 topn 族 30 个检验在 BH q=0.10 下通过数均为 0，与 Bonferroni 结论一致；此前 3 组常规 PASS（main-15-B、main-30-C、pit-30-C）在 BH q=0.10 下均不再属于通过集合，证据不足以支持其过门槛；加一校正敏感性对照下 full 端仍为 0 通过，不改变上述判断。

## 2. p 值定义与精度限制

pct 为安慰剂中低于真实值的比例，故单尾经验 p 值取 p = 1 - pct。原假设为真实策略与安慰剂同分布，p 越小表示真实值越极端。

三个 JSON 实读的安慰剂次数：fairplacebo meta.placebo_n = 100，timestamppit meta.placebo_n = 100，topn meta.placebo_n = 200（每档亦标 200）。离散经验 p 值的最小分辨率分别为 1/100 = 0.010、1/100 = 0.010、1/200 = 0.005。任务说明曾提及 fairplacebo 用 NPL=200，与该文件实读值 100 不一致，本报告一律以 JSON 实读为准。

pct = 1.0 时 p = 0，该 0 值表示分辨率以下的上界，其真实 p 至多为 1/NPL，不可解释为 p 精确等于 0。OOS 端出现多个 p = 0，相关结论需按此上界理解。

比较时 p 取 6 位小数，判定条件 p_(k) <= k*q/m 加 1e-9 容差，用于消除浮点表示误差（例如 1 - 0.96 与 12*0.1/30 的边界相等情形）。

另做加一校正敏感性对照：标准置换检验经验 p 值取 p = (count_ge + 1)/(N + 1)，其中 count_ge 为安慰剂中不低于真实值的个数，该口径保证原假设下 p 值的统计有效性。本报告主结果按任务要求用 p = 1 - pct，加一校正结果列于第 5 节末，仅作稳健性参照。

## 7. 边界与局限

BH 控制的是错误发现率，含义为在通过集合的期望中错误拒绝的比例不超过 q。它不控制任一单次结论的犯错概率，也不等于证明因子有效。

p 值由安慰剂分位近似得到，精度受 NPL 限制（0.01 或 0.005），属离散经验值，解析分布尾概率在此不适用。p = 0 仅代表低于分辨率，不能按精确零解释。

安慰剂在逐信号独立域内抽样，三者分位互不可比，各自与自身真实值可比。族内合并排序用于多重比较控制，不用于跨信号强弱排序。

全量族与 topn 族存在包含关系，属两种口径并列报告，不构成相互独立的两次验证。OOS 端与 full 端共享样本区间，结论仅作稳健性参照。

加一校正对照显示 OOS 端通过集合对 p = 0 的处理方式敏感，Bonferroni 通过数由 7/5 降为 0/0，BH 由 17/12 降为 16/11。OOS 端本作稳健性参照，该敏感性不改变 full 端 0 通过的核心结论，也不改变 3 组常规 PASS 不可采信的判断。

所有结论措辞限定为证据不足与未过门槛，不涉及因子有效性定性。
