# 冠军因子第三口径复核：时点化 ST/退市排除

日期：2026-11-22 ｜ 负责人：A（team-lead）｜ 状态：结果已落盘，待 E 独立复核措辞

## 一、结论先行

1. **三组信号在第三口径下常规与严格门槛全部 FAIL**，与 main、pit 两口径结论一致。冠军因子「证据不足以支持对外宣称有效」的判定在三种排除口径下都成立，未出现口径反转。
2. **补上了此前最大的口径缺口。** 此前 main 用纯板块 mask（不排除 ST），pit 用静态曾用名快照（含未来信息），两者都不是真正无前视的时点排除。第三口径用 iFinD 戴帽摘帽时间构造逐交易日 ST/退市状态，首次做到无前视排除。
3. **样本外出现孤立高分，但全样本不稳，属典型过拟合形态。** 冠军A、冠军C 样本外分位都到 0.990，但全样本分位只有 0.550、0.730，全样本最大回撤 -0.418、-0.316，且 biggest-year 剔除后跌破 1.0。样本外好、全样本差，方向相反，不足以支撑有效结论。
4. **时点化排除让全样本回撤变大，但幅度有限。** 冠军A 全样本 mdd 从 main 口径 -0.3723（权威值，见 fairplacebo JSON）恶化到 -0.4183，幅度约 0.046；样本外 mdd 两口径均为 -0.1552，完全不变。回撤集中在 2019-04 至 2022-10（865 个交易日水下、41.2 个月）。此前曾误把样本外 mdd -0.1552 当成 main 全样本值，经 E 复核更正。这个方向合理：时点化排除把 ST/退市股从候选池剔除，全样本回撤略增，样本外不受影响。

## 二、口径定义与实现

### 2.1 三种排除口径对比

三者是三个不同的可交易性假设，并列呈现，不设主次（E 第十二节）。

| 口径 | mask 组成 | 静态前视 | 定位 |
|---|---|---|---|
| main | `tradeable_mask` 纯板块过滤，不叠加任何 ST/退市排除 | 无 | 纯板块过滤结果，排除范围最宽 |
| pit | main + `exclude_st_pit.json`（821 只曾用名含 ST/退/PT） | 有 | 静态曾用名剔除，含前视，仅对照 |
| **timestamppit（本次）** | main 板块 mask + signal 层逐日 ST/退市排除 | **无** | **时点化 ST/退市排除，无前视，新增对照** |

注：第三口径消除静态前视，但相对 main 反而放宽排除范围（main 完全不排除 ST，第三口径逐日排除 811 只），不是 main 的"严格版"，倍数不可直接比高低。

### 2.2 时点化状态判定

数据源 `st_pit_intervals.json`（C 产出，iFinD「戴帽摘帽时间」字段）：覆盖 6142 只股票（文件顶层另有一个 `_meta` 键，故 JSON 键数为 6143），1319 只有 ST 区间共 1801 个区间，350 只有摘牌日期，225 只 end_missing。面板 5812 只 100% 覆盖。`name_hint_only=0` 是全量交叉校验跑完后的真实结果：本地曾用名含 ST 的 821 只中 820 只被 iFinD 戴帽字段命中，唯一未命中的 001267 汇绿生态经核查 A 股上市后从未戴帽；另对 4824 只戴帽字段为空的股票全量扫描证券曾用名，含 ST 者为 0，无漏网标的。

`st_active(t) = 任一 ST 区间 [start, end) 命中 OR t_date >= delist`，两者取或。

- ST 区间左闭右开：戴帽日当天算 ST，摘帽日当天不算。
- delist 摘牌日当天起算退市，之后持续排除。
- end 为 None（end_missing）表示开放区间，从最后一次戴帽日起持续排除。
- **衔接坑（C 提示，已验证规避）**：265 只末位戴帽未摘股票的开放区间 end 被设成 delist，按 [start, end) 在 delist 当天区间已关闭；只查 intervals 会在 delist 当天误判为可买。本口径用"区间命中 OR t_date>=delist 取或"，已验证 delist 当天 st_active=True（样本 000004），无此漏洞。

### 2.3 实现方式（不改生产引擎）

在 signal_fn 层注入：算出当天真实信号后，把 `st_active[t]` 为 True 的候选 signal 置 nan，使其不进入选股域。静态 mask 仍为 `tradeable_mask`。安慰剂在同一过滤后的 finite 集合内随机打分，候选域与真实策略严格一致，逐信号独立分布。

区间语义与 searchsorted 对齐已做冒烟验证：以 000004 为例，2022-05-05（戴帽前）False、2022-05-06（戴帽当天）True、2023-06-27（摘帽前日）True、2023-06-28（摘帽当天）False、2026-07-14（delist 当天）True 且之后持续。逐条符合 C 的语义确认。

启动诊断：st_grid 2124 交易日 × 5812 股，研究区间内 811 只受 ST 排除影响，2018-01-02 当日三信号分别排除 40 / 57 / 39 只（排除前候选 2843 / 2662 / 2469）。成本 `cost_of(topn=20)=24.826bp`。

五要素标注：信号 magic/cash/combo、topn=20、mask=main 板块 + 时点化 ST 排除、成本 24.826bp、exclude 为 st_pit_intervals.json 逐日时点化无静态前视。

### 3.1 逐项未过门槛原因

- **冠军A**：分位F 仅 0.550，全期倍数 1.3496 在全期安慰剂分布里只排到中位偏上；剔除 2024 年后全期 0.8839（跌破 1.0）。分位O 0.990 虽高，但样本外孤立达标不成立整体门槛。50bp 成本下 1.0429 勉强>1.0。
- **冠军B**：分位F 0.800、分位O 0.870，双双未到 0.90；全期与样本外都只是温和正收益。
- **冠军C**：分位O 0.990 高，但分位F 0.730、剔除 2024 年后 1.0891 接近临界，全期回撤 -0.3162。

## 四、口径边界与解读纪律

沿用 E 第十一节确立的克制口径，本口径同样适用：

1. **"全部 FAIL"的含义**：三组均未通过本系统自设的常规与严格门槛，证据不足以支持对外宣称有效。这**不等于被证否**，也不等于负收益。三组真实全期倍数 1.35-1.68、样本外 1.38-1.90，全部为正，且都高于各自安慰剂中位数。
2. **跨信号分位不可横向对比**：三个信号安慰剂域不同（combo 域为 magic∩cash），0.990 与 0.730 不能直接比大小，只各自与本信号真实值比较。
3. **样本外分位接近严格线不等于有效**：冠军A、C 分位O 0.990 已过 0.983，但分位F、回撤、剔除最好年份三项都不达标。样本外孤立高分叠加全样本不稳，是过拟合的典型形态，不是有效性的证据。
4. **end_missing 保守偏向**：225 只 end_missing 中 47 只在面板内，iFinD 漏最后一次摘帽事件，本口径按开放区间从最后一次戴帽日起持续剔除。这会让这些股票在摘帽后仍被排除，方向偏保守，可能略微低估收益。即便如此结论仍是 FAIL。
5. **时点数据本身的质量边界**：iFinD 数据无前视，优于静态快照，但 end_missing 缺口说明字段并非完备。后续若有更完整的摘帽事件源，可复核这 47 只的影响。

## 五、业务结论

1. 冠军因子在 main、pit、timestamppit 三种排除口径下全部未过门槛，判定稳定，不因排除口径改变而翻转。
2. 三口径是三个不同的可交易性假设，并列呈现、不设主次（E 第十二节）：main 给出纯板块过滤结果，pit 给出静态曾用名剔除（含前视，仅对照），第三口径给出时点化 ST/退市排除结果。第三口径消除了静态快照前视，但相对 main 反而**放宽**了排除范围（main 的 3391 只 mask 完全不排除 ST，第三口径逐日排除 811 只受影响股票），因此它不是 main 的"严格版"，两者倍数不可直接比高低。冠军A 样本外从 1.9911 降到 1.9033 是口径变化，不是策略退化。
3. 保留冠军因子流水线作研究用基准与对照，不对外宣称有效，不作实盘重仓依据。三组 FAIL 的原因是 pctF 与 drop_best，冠军A/C 的 pctO=0.990 须放在"样本外孤立高分"语境下呈现，不单独当作有效性证据。
4. 方法论资产（signal 层时点化注入、逐信号独立域安慰剂、双/三口径对照、随机基线落盘、多重比较门槛）可复用到后续因子验证。
