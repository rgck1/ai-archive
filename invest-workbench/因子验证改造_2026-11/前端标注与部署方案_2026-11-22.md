## 零、结论先行

1. **回测口径标注要写在分片里，不要直接改 index.html。** index.html 是 `parts/` 分片的构建产物，部署脚本 `deploy_frontend_now.py` 开头强制跑 `build_frontend.py --check`。直接改 index.html 会在部署时被中止。真正的编辑位置是 `parts/views/view-recs.html` 第 117 行与第 118 行之间。
2. **冠军因子页的数据没有任务描述里说的那么旧。** 线上与本地的 `asof` 都是 2026-11-17，今天 2026-11-22，距今 5 天。任务描述里的 2026-10-08 是上一版旧值，已在 v97（2026-11-18）更新。陈旧度徽标仍值得做，它能在未来数据停更时自动报警。

5. **静态文件部署脚本不自动备份。** `deploy_frontend_now.py` 与 `deploy_factor_picker.py` 直接 install 覆盖，部署前必须手工备份 index.html、sw.js、factor-picker.html。`server.py` 与 `engine/server.py` 由各自脚本自动备份。

```js
function dayDiff(asof){
  var p = String(asof || '').split('-').map(Number);
  if(p.length !== 3 || !p[0] || !p[1] || !p[2]) return null;
  var a = Date.UTC(p[0], p[1] - 1, p[2]);
  var n = new Date();
  var t = Date.UTC(n.getFullYear(), n.getMonth(), n.getDate());
  return Math.max(0, Math.round((t - a) / 86400000));
}
function renderFreshness(){
  var d = dayDiff(DATA.asof),
      el = document.getElementById('freshBadge'),
      ban = document.getElementById('staleBanner'),
      at = document.getElementById('asofText');
  if(at) at.textContent = DATA.asof;
  if(d === null){ if(el){ el.className = 'fresh mid'; el.textContent = '数据日期待核实'; } return; }
  var lv = d <= 7 ? 'ok' : (d <= 30 ? 'mid' : 'old');
  var txt = d === 0 ? '当天数据' : ('距今天 ' + d + ' 天');
  if(el){
    el.className = 'fresh ' + lv;
    el.textContent = txt + (lv === 'ok' ? ' · 数据新鲜' : (lv === 'mid' ? ' · 数据偏旧' : ' · 数据陈旧'));
  }
  if(ban){
    if(lv === 'ok'){ ban.style.display = 'none'; }
    else {
      ban.style.display = 'block';
      ban.className = 'stale-banner ' + lv;
      ban.innerHTML = '<b>' + (lv === 'old' ? '数据陈旧提醒' : '数据偏旧提醒') + '</b>：名单数据截至 ' + DATA.asof + '，距今天 ' + d + ' 天。' +
        (lv === 'old' ? '实盘前请务必刷新底层数据并重新生成名单，历史名单不代表当前推荐。' : '实盘前请先确认底层数据已刷新。');
    }
  }
}
```

改动三，第 139 行：把原调用行替换为下面这行。

```js
renderSens(); renderTabs(); renderStrat(); renderFreshness();
```

实现要点：天数差用 `Date.UTC` 对齐到双方零点的 UTC 时间戳，避开浏览器时区与夏令时导致的整天误差。数据日期缺失或格式异常时显示「数据日期待核实」，不编天数。
