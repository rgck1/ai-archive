# P0-A1 冠军因子异常复核结论

> 复核时间：2026-11-22 ｜ 负责人：A（team-lead） ｜ 方法：源码静态审计
> 触发问题：`champion_verify_result_latest.json` 中神奇公式样本外夏普 5.62、日胜率 65.6%、安慰剂分位 1.0，数值异常。

## 结论

**异常根因不是财务数据的前视偏差，而是回测引擎把每 20 天持仓期的收益平摊成固定日收益， synthetic 平滑序列使波动率被严重低估，夏普与胜率因此虚高。**

原先"先查 PIT"的假设经源码审计排除。P0-A2 的任务重心相应调整。

## 根因机制（第一性原理）

cs_flex 的原始代码：

```python
rr = np.clip(sp[good]/bp[good] - 1.0, -0.6, 1.0) - cost
period = float(np.mean(rr))                      # 一个 20 日持仓期的总收益
...
daily = (1.0 + period) ** (1.0 / (seg1 - seg0)) - 1.0
rets[seg0 + 1:seg1 + 1] = daily                  # 把总收益平摊成 20 个相同的日收益
```

随后 `xbx_engine.py` 第 154 行计算夏普：

```python
sharpe = mean(rr) / std(rr) * sqrt(244)
```

问题在于：

1. **波动率被系统性抹平**。真实净值在每个持仓期内逐日波动，此处被替换成一条直线。20 天内 `std` 接近 0，仅剩持仓期之间的差异。夏普分母缩小，数值放大，量级约为 √20（约 4.5 倍）。
2. **最大回撤被隐藏**。持仓期内部的回撤（例如第 10 天浮亏 8%）在平滑序列里完全不可见，所以样本外 mdd 仅 -9.63%，明显偏低。
3. **日胜率语义失真**。65.6% 实际是"20 日持仓期为盈利的天数占比"，并非真实逐日胜率，不可用于判断择时稳定性。
4. **单一年份主导**。神奇公式 2024 年收益 +46.13%，去掉该年后全期倍数从 1.54 降到 1.0556。样本外窗口 2023-01-01 起共 3.75 年，收益高度集中于一年，`placebo_oos_pct=1.0` 在 100 次抽样、单一年份主导下证据强度有限。
