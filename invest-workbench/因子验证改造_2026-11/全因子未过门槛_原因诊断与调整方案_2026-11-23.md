# 全部因子未过验证门槛：原因诊断与可执行调整方案

日期：2026-11-23 ｜ 负责人：A（team-lead）｜ 触发：用户询问"当前显示所有内容均无法通过"的原因与改进

## 零、先说结论

1. **"全部无法通过"本身不是 bug，是验证流程在正常工作。** 这批因子在三种排除口径、30 组参数搜索下全部未过严格门槛，与联网检索到的学术界结论一致：Harvey、Liu、Zhu（2016）检查了 316 个已发表因子，多数在多重比较校正后站不住。我们的验证体系做对了该做的事，没有把一个过拟合的假象当成有效因子放上线。
2. **但"不通过"不等于"因子一定无效"，也不等于"系统白做了"。** 当前结论是"证据不足以支持对外宣称有效"，不是"已证否"。真实收益全部为正（全期 1.50-1.86 倍，样本外 1.40-1.99 倍），且高于安慰剂中位数 1.17-1.68 倍。
3. **真正需要改的是三件事**：统计检验工具升级（补 DSR、PBO、FDR、walk-forward）、验证纪律升级（预注册、测试集锁箱、试验计数）、以及产品定位回退到"没有可用因子"的正确姿态（研究工具而非实盘依据）。
4. **对散户目标最关键的一句**：这套系统目前能给出的最可靠结论，恰恰是"没有可验证的选股因子可用"。联网检索的多篇资料指向同一务实路径：放弃选股博弈，转向宽基指数配置 + 定投 + 仓位纪律。这不是失败，是避开了把运气当能力的最大风险。

## 一、现象回顾（我们要解释的是什么）

| 验证批次 | 结果 | 门槛 |
|---|---|---|
| 冠军因子 main / pit 双口径 | 六组常规与严格全 FAIL | pct≥0.90 / 0.983 |
| 冠军因子 timestamppit 第三口径 | 三组常规与严格全 FAIL | 同上 |
| topn 持股数敏感性 30 组 | 常规 3 组 PASS、严格 0 组 PASS | 同上 |
| F1 ETF 折溢价闸门 | 暂缓（数据不可得） | 无法验证 |
| F2 红利均线偏离率 | 27 只中 1 只常规 PASS，主标的全 FAIL | 循环移位安慰剂 |

一句话：没有任何一个候选因子达到"可对外宣称有效"的证据强度。

## 二、原因分析（联网检索 + 项目实况对照）

检索来源涵盖学术界经典论文与业界方法论文章，归纳为四大类原因。每类都对照我们项目的具体证据。

### 原因一：多重比较与选择偏差（最核心，学术共识）

- 权威结论：Bailey、Borwein、López de Prado、Zhu（2014）《Pseudo-Mathematics and Financial Charlatanism》证明，在同一份数据上反复试够多组策略，光靠运气就能挑出夏普很高、样本外完全失效的回测。Harvey、Liu、Zhu（2016）提出新因子门槛应从 t=1.96 提到 t≈3.0。业界文章（shishin.io、equity-rank）给出算术：200 次零效应尝试中，至少出现一个 t>2 的概率是 99%。
- **我们的对应证据**：topn 搜索 5 档 × 双口径 × 3 信号 = 30 组，E 第十三节实测零假设下出现至少一组双达标概率约 26%，出现 3 组常规 PASS 完全在预期内。冠军A 样本外分位 1.000、全样本却只有 0.690，是典型的"试出来的极值"。
- **判定**：这不是因子无效的唯一解释，但它解释了为什么"看起来好的那几组"不可信。

### 原因二：过拟合与数据结构依赖

- 权威结论：样本内夏普高、样本外迅速衰减是过拟合的典型信号；因子对参数极其敏感（稍微调整就大幅下滑）也是过拟合特征（yueniuzq 问答、binaryfintech）。真正的稳健设置应位于"平台"而非"尖峰"。
- **我们的对应证据**：冠军A 逐年分位 9 年里大量年份低于 0.90（2018 -20.4%、2020 -9.6%、2022 -8.7%），2024 单年 +54.3% 撑起全期收益，剔除 2024 后全期不赚钱。topn 的 3 组 PASS 中 2 组是孤立尖点（相邻档位全 FAIL）。这些都是过拟合形态，不是稳健平台。
- **判定**：这批因子确实带有过拟合特征，未过门槛是合理结果。

### 原因三：检验工具本身的局限（我们的方法学缺口）

- 权威结论：现代量化验证有成熟工具集（surmount.ai、quantframe.io、opulencealpha.ai）：
  - **DSR（Deflated Sharpe Ratio）**：按试验次数和收益非正态性压缩夏普；
  - **PBO（Probability of Backtest Overfitting）**：用 CSCV 组合交叉验证估计"样本内冠军在样本外低于中位数"的概率，>20-30% 即脆弱；
  - **White Reality Check / Hansen SPA**：对整批搜索过的策略做数据窥探校正；
  - **FDR / Benjamini-Hochberg**：比 Bonferroni 宽松、适合大量测试；
  - **walk-forward**：滚动训练/测试，模拟真实使用；
  - **lockbox / 预注册**：留出一次性测试集，事前锁定假设。
- **我们的对应缺口**：目前只用"安慰剂分位 + Bonferroni 阈值"，没有 DSR、PBO、SPA、FDR、walk-forward、lockbox。E 第十三节已指出严格线 0.983 只校正了 3 个信号，没覆盖 5 档 topn 与 2 口径，真要覆盖 30 组应设 0.9983（200/200），在 NPL=200 下几乎不可能通过。这说明我们的门槛设定本身也偏粗。
- **判定**：这是可改进的方法学缺口，需要补工具，而非简单放低门槛。

### 原因四：数据质量与交易现实（已部分处理，仍有残余）

- 权威结论：幸存者偏差、前视偏差、未扣成本、样本太短、指数成分时点化，都会让回测偏乐观（finlab、quantframe 清单）。
- **我们的对应处理**：已完成财务 PIT、逐日盯市、时点化 ST 排除、退市压力测试、动态成本，这几项做得比多数私人回测严谨。残余：end_missing 47 只开放区间保守剔除、2024 单年依赖、样本仅 2018-2026 约 8 年且未跨完整长周期。
- **判定**：数据层面主要风险已控制，剩余是样本长度和年份集中度问题。

### 关于"门槛是不是设得太严"

检索明确提示双向风险：Bonferroni 类校正保守，会误杀真实信号（prop-ledger、aligrithm、equity-rank）。也有资料指出真实但微弱的信号本来就需要很长历史才能显著（真实 Sharpe 0.5 十年数据期望 t 仅约 1.6）。但**这不能成为放低门槛的理由**：我们的目标不是"凑出一个能上线的因子"，而是"只把真正可靠的拿给用户"。在数据与工具不到位时，宁可维持"不通过"。正确做法不是降门槛，是补工具、加样本、锁参数后重新验证。

## 四、可行替代路径（按投入产出比排序）

### 路径 A：立即可做，不重跑回测（推荐先做）

前置核查（2026-11-23）：现有结果 JSON 只存汇总指标（倍数/分位/回撤/夏普），**不含逐日收益序列**，因此 DSR、PBO 无法用现成数据直接算，需要重跑导出日序列，已归入路径 B。路径 A 只保留不依赖序列的动作。

1. **建立试验台账**：记录本轮所有跑过的配置（含被丢弃的），作为未来所有校正工具的分母。这是 DSR/BH/PBO 的共同输入，也是当前最缺的基础。
2. **年份集中度量化**：用已有 yearly 字段补一张"剔除 2024 后全期倍数"对照表（drop_best 已算部分），确认收益是否由单一年份驱动。
3. **产品定位保持降级**：前端按已拍板方案降级为研究页，标注未过门槛、不作实盘依据。不动线上。
4. **事实源写明边界**：把"26% 自然出现概率""严格 0 组""三口径并列不设主次"写入事实源，避免未来被误读成有效因子。

产出：试验台账 + 年份集中度对照 + 已降级的前端 + 事实源边界说明。预计 1-2 小时。DSR/PBO 作为路径 B 的第一步。

### 路径 B：中等投入，需要重跑（若用户想进一步验证）

1. **升级检验工具**：实现 Benjamini-Hochberg FDR 控制（q=0.10），配合 Bonferroni 并列报告；用 stationary bootstrap 做 White Reality Check。
2. **walk-forward 重跑**：滚动训练窗口（如 3 年）、测试下一段，拼接所有 OOS，替代当前单点 OOS。参数在训练段锁定，测试段绝不回头调。
3. **PBO / CSCV**：把 30 组收益矩阵切成多个时间块，估计样本内冠军在样本外的排名分布，PBO>30% 判脆弱。
4. **参数平台检查**：topn 5/10/15/20/30 之外补 12/18/25，看 PASS 是否连成平台。若补档后 PASS 消失，坐实尖点。

产出：升级版验证报告。预计半天到一天回测时间（walk-forward 计算量约为当前 2-3 倍）。

### 路径 C：高投入，数据驱动（仅在有增量数据时）

1. **延长样本**：当前 2018-2026 不足一个完整长周期。拿到更早的 PIT 数据（如 2010 起）后重跑，检验因子跨牛熊稳健性。
2. **独立数据验证**：在全新股票池或全新时间窗上，对预先锁定的参数做一次性确认（lockbox）。这是"证明有效"的最强证据，也是最难的。
3. **多市场确认**：同类因子在港股/美股同类标的上是否有同向效应，作为独立佐证。

产出：跨周期/跨市场验证报告。预计一至数周，取决于数据可得性。

### 路径 D：产品与投资目标回退（对散户最务实）

联网检索的散户生存资料（头条案例、MoneyDJ、新浪财经、微信公众号）高度一致：放弃短线选股博弈、拥抱宽基指数、定投 + 仓位纪律 + 资产配置。结合本项目结论，给出务实建议：

1. **把工作台定位为研究/记录工具**，不再作为选股决策依据。它的最大价值是"帮你识别哪些方法不可信"。
2. **投资主线转向宽基指数定投 + 股债金配置**：单只 ETF≤20%、单行业≤30%、常留 20% 现金（与检索案例一致）。
3. **若仍想用量化**：优先用指数增强、红利/自由现金流等有经济逻辑、公开验证过的因子工具，而非自研的、在当前数据上未过门槛的因子。
4. **保留纪律资产**：已有的仓位管理、成本口径、PIT 数据纪律，可迁移到配置型策略的执行与复盘。

这条路径不依赖任何回测通过，当下即可执行，且最贴合"长期活下去"的原始目标。

## 五、验证方式（怎么确认调整有效）

### 5.1 路径 A 的验证

- 试验台账产出，覆盖本轮全部正式批次与可追溯的探索性尝试，N 有据可查。DSR 报告归入路径 B，待导出日序列后产出。
- 前端 grep 验证：旧数字 2.0074 / 1.5426 / 1.06× / asof 2026-11-17 零残留；新数字 1.501 / 1.863 / 1.727 已注入；"冠军"字样在可见文案清零。
- 事实源 grep：三口径并列、26% 概率、严格 0 组、不加"有效/已验证"等误导措辞。
- 不部署：线上页面版本号保持 v110 不变。

### 5.2 路径 B 的验证

- FDR 与 Bonferroni 并列表：BH q=0.10 下的通过集合应与 Bonferroni 对照，差异有解释。
- walk-forward 拼接的 OOS 净值曲线，与当前单点 OOS 对比；若显著下降，坐实原先过乐观。
- PBO 数值与解释：>30% 判脆弱，并说明是否改变结论。
- 参数平台图：topn 轴上的 pctF/pctO 曲线，PASS 是否连片。孤立尖点必须标注。
- 全部结果交 E 独立复核（延续第十二、十三节的对抗式风格）。

### 5.3 路径 C 的验证

- 跨周期/跨市场结果与当前样本方向一致，且各自通过 DSR 校正。
- lockbox 只测一次，测后不再调参；若回头调，作废重来。

### 5.4 路径 D 的验证

- 配置方案有明确的仓位上限、现金比例、定投节奏、再平衡规则，且不依赖任何未验证因子。
- 用工作台的复盘模块记录执行纪律（是否守纪律比选股更重要），按月回顾。

## 六、给用户的决策建议

1. **先做路径 A**（1-2 小时，不重跑回测），把当前结论的证据强度量化清楚，前端保持降级。这一步性价比最高。
2. **同步执行路径 D**，因为它贴合"长期活下去"目标，且不依赖任何回测结果。
3. **路径 B 视你的兴趣决定**：如果想知道"换了更严谨的检验会不会翻盘"，值得做；如果只是要一个能用的投资方案，可以不做。
4. **路径 C 暂缓**：需要增量数据，投入大，当前没有数据源。
5. 任何路径都不改变当前部署冻结状态，上线仍须单独批准。
