## 三、关键技术结论（接手者必须掌握）

1. **根因**：`v3_s02_deepdive.py` 第 146-155 行把 20 日持仓总收益平摊成固定日收益，平滑序列使 std 缩小、夏普虚高约 √20 倍、回撤隐藏、日胜率语义失真。不是财务 PIT 前视。
2. **修复**：七处平摊逻辑改为逐日盯市（mark-to-market），用 `ret_clean`，t 日收盘算信号、t+1 收盘成交、t+2 至卖出日逐日计收益，成本建仓日扣一次。展示口径 √252，引擎常量 `xbx_engine.TRADING_DAYS=244` 属策略定义暂不改。
3. **三种排除口径，并列不设主次**：
   - main：`tradeable_mask` 纯板块过滤，无静态前视，排除范围最宽
   - pit：main + `exclude_st_pit.json`（含未来信息，仅对照）
   - timestamppit：signal 层逐日注入 ST/退市排除（`st_pit_intervals.json`），无前视
4. **冠军因子最终判定**：三口径六组/三组全部未过门槛。真实值全为正且高于安慰剂中位数 1.17-1.68 倍，但分位不达标，属"样本外孤立高分、全样本不稳"的过拟合形态。措辞用"证据不足以支持对外宣称有效"，**不要用"已证否"或"负收益"**。
5. **topn 敏感性**：30 组中常规 3 组 PASS、严格 0 组。3 组常规 PASS 判定为多重比较运气（零假设下出现概率约 26%），不采信。主口径锁死 topn=20。
6. **F1 ETF 折溢价闸门**：数据不可得，整体暂缓。**F2 红利均线偏离率**：27 只仅 1 只常规 PASS，主标的全 FAIL，不通过、不上线。
7. **统计工具缺口**：DSR/PBO/FDR/walk-forward 尚未做，现有结果 JSON 不含逐日收益序列，补算需重跑导出序列（详见诊断报告路径 B）。
