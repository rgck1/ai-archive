## 二、决策与规则明细（供审核决策合理性）

1. **资讯默认源 = eastmoney（固化，非热配置）**：v86 阶段仅靠 `data/news_cfg.json` 热配置切源；v87 把 `server.py` 默认源常量 `_NEWS_DEFAULT_SOURCE="eastmoney"`，删文件即回退到 eastmoney 而非旧默认 10jqka。同花顺接口经实测**本机/服务器均 404（源废弃）**，代理救不了 → 不保留同花顺为默认。
2. **三项短线范式口径**：不做模拟盘、不预判买卖价、不给买入指令；打板/尾盘明确「仅复盘、非投资建议」，数据全部真实（东财 push2ex 涨停池真实封板 / 大盘 `api_market_state`）。
3. **通用折叠**：CSS 只用 `var(--token)` 与 `--fs-*`，不新增 style 块；`localStorage wb_fold_v1` 记忆 `data-wb-fold` 的 open 状态；toggle 同步移动端克隆副本（移动端 id 重复按属性遍历）。
4. **归因名称与基准**：`api_trade_attribution()` 建 names 映射（台账 `trades.json` 自带 name → `my_holdings.json` 兜底 → 6 位代码回退）；**不逐笔请求行情接口**（165+ 笔会打爆公开源）。v92 起基准改为每笔 `buy_date→sell_date` 区间沪深300收益；取不到返回 None，前端超额列显示"—"（不再显示 0 或统一基准）。**原缺陷已修复，见第六节 6.3**。
5. **净值停更根因**：服务器 IP 被雪球 301 风控（阿里云反爬页），与 Cookie 无关；`auto_refresh.json` 关闭于 2026-11-13。数字口径区分：`nav_codes.txt` = 抓取清单 **74** 个（core5+watch27+休眠42）；服务器上 `nav_ZH*.json` 文件实测约 **87** 个（历史累积，含已不在当前抓取清单的组合；差额 13 个本会话未逐一核对来源）。两批文件 mtime 均停在 2026-10-27。恢复只能靠**本机住宅 IP 抓取 + TAT 推送**。
6. **组合名来源**：只来自雪球实时抓取；5 个无名组合是云 IP 停更后才加的、从没被服务器抓过。补名链路 = 本机取真名 → TAT 写 `cube_names.json` → **重启服务刷新内存缓存**。新加组合由 `onAddPf` 回拉 `/api/names` 即时重绘，但服务端无名时仍提示人工补位 → **半自动，非闭环**。
7. **测算表规则（透明口径，仅供参考）**：止损=成本×0.92（浮亏单）或保本线（浮盈单）；目标=`max(成本×1.2, 现价×1.1)`；介入区=`min(成本,现价)` 下方 1–3%。截图里财通福鑫 MA60=9.24 vs 现价 5.86 偏差过大，未直接套用均线。

## 五、给审核智能体的复核指引（重点排查项）

- **【坑 1 · 部署不重启】**：前端部署只推 `index.html`+`sw.js`，**不会重启 `invest-workbench` 服务**。任何改服务端内存缓存（如 `cube_names`、其它启动加载的全局 dict）的操作，必须 `systemctl restart` 才生效。v90 即踩此坑：文件写对但线上 `/api/names` 仍旧，重启后才生效。v91 因改了引擎，已随引擎部署一并重启。**审核任何"数据已更新"结论时，先确认是磁盘生效还是内存生效。**
- **【坑 2 · 云 IP 风控】**：服务器侧任何打雪球（`nav_daily`/取名）的请求目前都失败（IP 级 301 反爬），**不能**用服务器出口验证 Cookie 有效性；Cookie 是否有效只能在用户住宅 IP 验证。
- **【坑 3 · 公开源额度】**：持仓归因/监控台行情走腾讯/新浪公开源，已在 `api_trade_attribution` 规避逐笔行情；审核时勿主张"给每笔归因再去拉一次实时价"。
- **【口径一致性】**：涨红跌绿（中国惯例）；`--up/--down` 令牌永不覆写；前端零裸 hex、字号仅 `--fs-*`、禁 `!important`；每次前端变更必 bump `sw.js`。
- **【构建铁律】**：前端真值源是 `parts/`，`index.html` 是构建产物禁手改；新增片段须登记 `manifest.json`；移动端 `openFeature()` 克隆导致 id 重复，渲染须 `querySelectorAll('[data-...]')` 遍历。
- **【可复算性】**：v91/v92 核验脚本 `_verify_v91_live.py`、`_verify_v92_live.py`、`resolve_names_local.py`、`refresh_nav_local.py` 均保留在源码目录、逻辑透明、纯标准库；建议审核者抽样核对 1–2 项。v89/v90 核验脚本为一次性、核验后删除，历史结论不可复现。
- **【坑 4 · 尾盘时区】**：v92 起尾盘时段用 `Asia/Shanghai` + 引擎交易日历（`market_status`，表只到 2026 年、缺年份自动退回只看周末，「宁可少休不可误休」）。审核时勿再以服务器本地 `weekday()` 复现旧问题。
- **【安全】**：`xq_cookie.txt`、TAT 凭据只在本机，切勿写入仓库或日志；公开仓库 `ai-archive` 中任何服务器地址已脱敏为 `<服务器地址>`；本文档不含任何令牌值或前缀。
