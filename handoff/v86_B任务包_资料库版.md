## 2. 技术契约（严格遵守，否则无法与 A 的 HTML 拼合）

### 2.1 既有全局函数，直接调用、不要重实现
`apiGet(path, timeoutMs)` / `apiPost(path, body)` / `$(id)` / `esc(s)` / `safeUrl(u)` /
`toast(msg)`；`cls(v)` → 正数 `"up"`(红涨) 负数 `"down"`(绿跌) 0 `"flat"`；
`fmtPctNum(v)` → v 已是百分数数值（1.5 → "+1.50%"）；
`state` 是全局状态对象，**只读**，不改结构；`switchTab(name)` 切页。

### 2.2 DOM 契约 —— A 会创建这些容器，id 与 data-v86 一一对应，**不许改名**
- 持仓页 `view-hold`：`#attrBox[data-v86=attr]` 归因 / `#riskBox[data-v86=risk]` 风控 /
  `#factorBox[data-v86=factor]` 因子
- 跟单页 `view-recs`：`#aiInsightBox[data-v86=ai]` AI 洞察 /
  `#recsHitBox[data-v86=hit]` Top3 稳定性
- 情绪页 `view-mood` 的「收盘复盘」子视图：`#mktBreadthBox[data-v86=mkt]` 大盘趋势结构 /
  `#sectorTempBox[data-v86=temp]` 行业温度象限 / `#newsFeedBox[data-v86=news]` 资讯
- 每个面板另有提示行 `<div data-v86-sub="同上的 key">`。

### 2.3 移动端克隆（关键）
切页约 800ms 后会把 `#view-*` 的 innerHTML **克隆**进 `#mFeature .m-feature-body`，
导致 **id 重复**。因此：
- **禁止**用 `getElementById` / `$()` 写容器；必须
  `document.querySelectorAll('[data-v86="key"]')` 遍历**所有副本**逐个写 innerHTML；
  提示行同理用 `[data-v86-sub="key"]`。
- 请实现 `_v86Set(key, html)` / `_v86Sub(key, text)` 两个 helper 统一处理。
- 交互按钮**禁止** addEventListener 绑单个节点（克隆后失效），改用**事件委托**：
  `initV86()` 里对 `document` 绑一次 `click`，用 `ev.target.closest('[data-v86-act]')` 分发。
  这是 A 会调用的唯一初始化函数。

### 2.4 A 在 HTML 里放的交互控件（你只实现委托响应，不改 HTML）
- `<button data-v86-reload="hold|recs|mood">` → 调对应 load
- `<input data-v86-bl-code>`、`<input data-v86-bl-reason>`、`<button data-v86-bl-add>` → 加黑名单
- 删除按钮由你渲染成 `<button data-v86-bl-del="代码">`（接口 `?action=del&code=...`）
- `<button data-v86-ai-refresh>` → `/api/ai_insights?refresh=1`
- 资讯降级时给 `<button data-v86-act="goto-blog">` 调 `switchTab("blog")`

### 2.5 必须导出的全局函数（名字不许改）
```
initV86()                 // 只绑事件委托，幂等；A 在 boot 里调
loadV86Hold(force)        // async，加载 attr/risk/factor
loadV86Recs(force)        // async，加载 ai/hit
loadV86Mood(force)        // async，加载 mkt/temp/news
```
三个 load 要**并发**请求各自面板、彼此独立失败隔离（一个失败不影响其余），
有 busy 标志防重入，`force` 时跳过节流。失败时给对应容器写
`[STALE] 本次读取失败，保留上一版` 标记，**不清空已有内容、不编造数据**。

### 2.6 八个数据源（字段精确，已上线）

**1) `/api/trade_attribution`**
```
{ok, available, count, closed, open, total_pnl, win_rate, bench_ret_pct,
 rows:[{code,qty,buy_date,buy_price,sell_date,sell_price,pnl,ret_pct,
        annual_pct,hold_days,bench_ret_pct,select_pct,open}]}
```
百分数均为数值（如 -3.21 = -3.21%）；`open:true` 为未平仓（pnl=null）单独分组、不计胜率；
`select_pct` 标「选股超额」；盈亏用 cls() 上色。
不可用：`{ok:false, available:false, reason, rows:[]}`。
展示：概览（平仓笔数/总盈亏/胜率/基准收益）+ 逐笔表。

**2) `/api/risk_control`**
```
{ok, available, total_mv, port_daily_vol_pct, var95,
 stress:[{scenario,loss}], blacklist:[{code,reason,at}],
 exposure:[{code,name,mv,daily_vol_pct}]}
```
增删：`?action=add&code=600519&reason=xxx` / `?action=del&code=600519`
（用 encodeURIComponent），操作后重载本面板。
必须写明口径：VaR95 = 1.645 × 组合日波动率 × 总市值；个股波动率取近 60 日日线；
**假设持仓完全相关（保守上界）、未计分散化**；市值按 买入价×手数×100 估算、非实时市值。
不可用：`{ok:true, available:false, reason, blacklist, var95:null, stress:[], exposure}`。
展示：VaR95/组合日波动率/总市值 三个大数 + 4 档压力测试表 + 逐票敞口 + 黑名单列表。

**3) `/api/ai_insights`**（`?refresh=1` 强制重算）

**4) `/api/recs_hitrate`**

**5) `/api/sector_temperature`**

字段真实含义：`signal_pct` = 申万一级行业**当日涨跌幅(%)**，`flow` = **主力净流入(亿元)**，

- 对 31 个行业分别算 `signal_pct` 的横截面分位 `pctRank` 与 `flow` 的分位 `flowRank`

- 每行业两条分位条 + 绝对涨跌/净额小字；按象限分组展示，突出两类背离；`status` 忽略
- 明确标注「与收盘复盘热力网格同源，此处为横截面相对位置与量价配合，
  非重复展示绝对涨跌；不构成趋势判断」
