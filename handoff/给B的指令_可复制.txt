【4. 技术契约（严格遵守，否则无法与 A 的 HTML 拼合）】
4.1 既有全局函数，直接调用、不要重实现：
  apiGet(path, timeoutMs) / apiPost(path, body) / $(id) / esc(s) / safeUrl(u) / toast(msg)
  cls(v) → 正数 "up"(红涨) 负数 "down"(绿跌) 0 "flat"
  fmtPctNum(v) → v 已是百分数数值(1.5 → "+1.50%")
  state 是全局状态对象，**只读**，不改结构；switchTab(name) 切页。
4.2 DOM 契约 —— A 会创建这些容器，id 与 data-v86 一一对应，**不许改名**：
  持仓页 view-hold：  #attrBox[data-v86=attr] 归因 / #riskBox[data-v86=risk] 风控 / #factorBox[data-v86=factor] 因子
  跟单页 view-recs：  #aiInsightBox[data-v86=ai] AI洞察 / #recsHitBox[data-v86=hit] Top3稳定性
  情绪页 view-mood 收盘复盘： #mktBreadthBox[data-v86=mkt] 大盘趋势结构 /
                              #sectorTempBox[data-v86=temp] 行业温度象限 / #newsFeedBox[data-v86=news] 资讯
  每个面板还有提示行 <div data-v86-sub="同上的 key">。
4.3 移动端克隆（关键）：切页约 800ms 后会把 #view-* 的 innerHTML 克隆进
  #mFeature .m-feature-body，导致 **id 重复**。禁止用 getElementById/$() 写容器；
  必须 document.querySelectorAll('[data-v86="key"]') 遍历所有副本逐个写 innerHTML，
  提示行同理用 [data-v86-sub="key"]。请实现 _v86Set(key,html) / _v86Sub(key,text) 统一处理。
  交互按钮禁止 addEventListener 绑单个节点（克隆后失效），改用事件委托：
  initV86() 里对 document 绑一次 click，用 ev.target.closest('[data-v86-act]') 分发。
4.4 A 放的交互控件（你只实现委托响应，不改 HTML）：
  <button data-v86-reload="hold|recs|mood">  → 调对应 load
  <input data-v86-bl-code> <input data-v86-bl-reason> <button data-v86-bl-add>  → 加黑名单
  删除按钮由你渲染成 <button data-v86-bl-del="代码">（接口 ?action=del&code=...）
  <button data-v86-ai-refresh> → /api/ai_insights?refresh=1
  资讯降级时给 <button data-v86-act="goto-blog"> 调 switchTab("blog")
4.5 必须导出的全局函数（名字不许改）：
